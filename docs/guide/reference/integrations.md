# Integrasi webhook

Addon webhook perusahaan menggunakan outbox, HMAC signing, idempotency key, secret reference khusus perusahaan, dan pembatasan tujuan jaringan.

Lihat [panduan konfigurasi `orm-integration`](../../addons/orm-integration.md) untuk format event, secret environment, kebijakan retry, dan batas keamanan jaringan.
