The sequence is a gate order, not a CI queue. A pushed batch starts hosted checks; the next independent local batch may start immediately. Only a dependent hosted action waits for its exact upstream result. Each finished batch is locally tested, diff-reviewed, committed and pushed to `dev`; record local command/results and source SHA, then add hosted run IDs and issue status when they become terminal. Do not promote `main`, weaken a gate, create a third origin branch, or deploy the application.
