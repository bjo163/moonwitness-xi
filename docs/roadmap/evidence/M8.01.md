## Changes

- Changed promotion and main-to-dev sync defaults from workflow-wide write scopes to `contents:read`; their single mutating jobs retain only required job-level grants.
- Changed release default from `contents:write` to `contents:read`; both release verification and publication declare their distinct permissions explicitly.
- The workflow uses short-lived GitHub-provided job tokens; no personal access token or GitHub App credential is stored. A GitHub App is not currently required because branch events use explicit workflow dispatch where a follow-up run must occur. App setup remains documented separately if platform permissions change.
- PR jobs receive read-only token rights; workflows do not use `pull_request_target`. Reports are scanned before artifact upload and do not include token environment variables.
