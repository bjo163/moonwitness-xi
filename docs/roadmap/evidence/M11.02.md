## Contract

- `tasks.json` schema version 1 uses a stable `M<n>.<two-digit>` task ID, milestone, unique dependencies, output and safe detail path. Optional metadata has typed constraints for labels, priority, assignee, status and evidence; unknown properties are rejected by the validator.
- Remote identity is repository numeric ID plus Task ID. The ID is discovered from GitHub metadata during remote apply; no issue number or repository ID is hardcoded in the source index.
- The offline validator detects duplicate/malformed IDs, milestone mismatch, missing task/dependency/card, unsafe paths, dependency cycles, missing/duplicate master checkboxes, completion/evidence mismatch, absent linked evidence and inconsistent recorded status.
- Shared evidence links may cover an explicit contiguous task range, such as M1.02–M1.06, when that existing evidence file is linked from each relevant master checklist row.
- Validation is read-only. It does not query GitHub, create issues, write files, or mutate task/issue state.
