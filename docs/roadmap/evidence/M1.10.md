# M1.10 — Protect version tags

GitHub repository ruleset `Protect version tags` (ID `24442531`) is active for
`refs/tags/v*`. Its `update` and `deletion` rules prevent existing release tags from
being moved or removed. The ruleset has no bypass actors and reports that the current
user cannot bypass it. It does not restrict creation, so the release workflow can create
a new version tag after its checks pass.

## Verification

- The repository rulesets API returned the active tag ruleset with exactly the version-tag
  pattern, update/deletion rules, and an empty bypass actor list.
- The repository currently contains `v1.0.0-rc.1`; no existing release tag was changed.
- No destructive push was attempted to test enforcement. The rule configuration is verified
  from GitHub's authoritative ruleset API response.

GitHub documents `update` as allowing only actors with bypass permission to update matching
refs, and `deletion` as restricting deletion to bypass actors. See the
[repository rulesets API](https://docs.github.com/en/rest/repos/rules).
