## Follow-up — active-release assertion/evidence search (2026-10-17)

- Added an authenticated `GET /api/research/graph/search` backed by the verified active PostgreSQL release. It searches bounded query text across assertion claims/IDs and evidence IDs, approved source/edition IDs, locators, and parent assertion IDs. Results are capped at 25 and include a truncation flag so the Board asks readers to refine broad queries. The response contains only an assertion preview or an evidence reference; it never returns passage text.
- Search uses the same active-company membership check as relation explanations, rejects empty/whitespace-only queries, and returns only `INTERNAL` assertions and evidence whose parent assertion is also readable. The client exposes a strict result union, and the Board shows the active release digest while readers search claims/source/passages, find evidence linked to an assertion, and open the exact pinned passage.
