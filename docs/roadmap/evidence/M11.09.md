# Evidence M11.09 — Source-bound roadmap progress dashboard

## Status

Partial. A read-only local dashboard generator now aggregates all indexed roadmap tasks per milestone and emits Markdown or JSON bound to the exact source SHA and generation timestamp. It separates work completion from delivery evidence: without a fresh validated lifecycle snapshot, delivery is `unknown`, so checked boxes are never treated as verified, merged, or released. GitHub Projects projection/upsert and hosted report publication remain open; no project capability or stable remote issue-node mapping has been proven.

- Source branch: `dev`.
- Deliverables: `scripts/roadmap/progress-dashboard.mjs`, tests, and `pnpm roadmap:progress`.
- Remote GitHub Projects/Issues mutations: none.

## Report contract

- Groups tasks by milestone and reports `todo`, `running`, `blocked`, and `complete` work counts separately from `verified`, `main`, `released`, `planned`, and `unknown` delivery counts.
- Every report carries full source SHA, generated-at timestamp, item Task ID, milestone, optional priority, optional lane label, and lifecycle blockers.
- Lifecycle stages are used only when a supplied snapshot matches current source SHA and passes repository, age, task coverage, and dependency validation. Without a snapshot, every delivery stage is `unknown`.
- Markdown is suitable for a Pages/workflow artifact. JSON carries stable task-level fields for future dashboard or GitHub Projects mapping; current task labels can supply a `lane:<name>` value.
- `--output` is constrained to a repository-relative path. Default invocation writes the report to stdout and performs no network or GitHub mutation.

## Verification

- `pnpm test:roadmap`: unit fixtures cover milestone totals, complete-versus-released separation, no-evidence unknown states, lifecycle-backed stages/blockers, Markdown provenance, and malformed source SHA.
- `pnpm roadmap:progress -- --format json`: exercised locally against all 148 indexed tasks at source `cc2d39e2537b45393b6cfca0737178f3776cfa0e`; report totals were work `todo=41, running=8, blocked=0, complete=99` and delivery `unknown=148` because no fresh lifecycle snapshot was supplied. This makes the evidence boundary visible instead of inferring release state from checkboxes.
- `pnpm lint`, `pnpm format:check`, `pnpm typecheck`, `pnpm docs:check`, `pnpm docs:links`, `pnpm automation:check:roadmap`, and `git diff --check`: run before commit.
