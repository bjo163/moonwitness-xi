## Report contract

- Groups tasks by milestone and reports `todo`, `running`, `blocked`, and `complete` work counts separately from `verified`, `main`, `released`, `planned`, and `unknown` delivery counts.
- Every report carries full source SHA, generated-at timestamp, item Task ID, milestone, optional priority, optional lane label, and lifecycle blockers.
- Lifecycle stages are used only when a supplied snapshot matches current source SHA and passes repository, age, task coverage, and dependency validation. Without a snapshot, every delivery stage is `unknown`.
- Markdown is suitable for a Pages/workflow artifact. JSON carries stable task-level fields for future dashboard or GitHub Projects mapping; current task labels can supply a `lane:<name>` value.
- `--output` is constrained to a repository-relative path. Default invocation writes the report to stdout and performs no network or GitHub mutation.
