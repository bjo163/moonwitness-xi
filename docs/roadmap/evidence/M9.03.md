## Delivered behavior

- Added `@moonwitness/orm-workflow` with programmatic schema/seed manifest, versioned definitions, immutable instance configuration snapshots, append-only event history, approval quorum records, views/menus and a safe seeded draft→submit→approve/reject example.
- Runtime validates configuration, action/role/resource allowlists, requester/reviewer separation, company scope, optimistic revisions, duplicate approvals, idempotency-key collisions, timeout expiry and retry behavior.
- Added authenticated, company-scoped API list/start/detail/action routes. Starting a workflow checks the caller's read permission and row rule for its resource. Generic CRUD/RPC access to workflow internals is denied.
- Registered bounded expiry in the jobs worker and seeded cron through the scheduler; installed the addon in API/scheduler/worker.
- Included the package in root scripts, full unit/coverage runner, generated API/model reference, README and architecture diagrams. No explicit `any` was introduced.
