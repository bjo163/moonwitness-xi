# Evidence M7.01 (remote CI pending)

- Status: implementation and local verification complete; wait for the full push-CI run before closing the roadmap item.
- Added `scripts/release-classification.mjs` and `scripts/classify-release-commits.mjs`, exposed as `pnpm release:classify <base-ref> [head-ref] [--summary]`.
- Supported Conventional Commit types: `build`, `chore`, `ci`, `deps`, `docs`, `feat`, `fix`, `perf`, `refactor`, `release`, `revert`, `security`, `style`, and `test`.
- Classification contract: `feat` → minor; `fix`, `perf`, `revert`, and `security` → patch; `!` or a `BREAKING CHANGE` trailer → major; other supported types → no release. Highest severity wins. Unsupported/non-conventional source commit messages fail closed.
- Git merge commits are skipped by parent count; non-merge source commits are counted once by full SHA. The CLI resolves both refs to verified commit IDs before building the range.
- CI's full-history plan job validates each pushed/pull-request commit range with `pnpm release:classify ... --summary`, so malformed commit messages fail the required plan/gate.
- Local evidence: five classifier tests passed. `pnpm release:classify v1.0.0-rc.1 origin/main --summary` returned `minor`, 47 source commits, 22 skipped merge commits, and zero invalid messages. Lint, formatting, and actionlint passed.
