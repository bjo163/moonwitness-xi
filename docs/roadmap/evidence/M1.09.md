# Evidence M1.09

- Status: implementation ready; remote proof pending.
- `.github/workflows/sync-main-to-dev.yml` runs after a `main` push, on a single non-canceling concurrency group, and can also be manually dispatched.
- The workflow ignores stale `main` events, fetches both branches, and exits without changes when `dev` already contains `main`.
- Otherwise it creates a normal `--no-ff` merge on top of the observed `dev` SHA. Before pushing, it rechecks both remote SHAs; it skips if `main` advanced and fails safely if `dev` advanced. It never force-pushes.
- The actionlint CI check includes the sync workflow.
- Since the bot pushes with `GITHUB_TOKEN`, GitHub does not start a second push-triggered CI run for that bot push. The sync commit only changes ancestry; the merged content is already the exact content validated on `main`. Verify the remote run and graph after promotion before marking this milestone complete.
