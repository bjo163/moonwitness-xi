## Implemented

- `.github/workflows/deep-regression.yml` runs weekly on Tuesday and supports manual dispatch. It starts an isolated PostgreSQL service, runs the required PostgreSQL integration suite, jobs queue/recovery tests, and isolated backup/restore drill. It scans reports before uploading a short-retention JUnit artifact.
- Existing `browser-matrix.yml` covers Chromium, Firefox, and WebKit weekly. CodeQL and Gitleaks also run weekly on separate schedules; their manual dispatch does not count as scheduled coverage.
- `platform-audit.mjs` checks the most recent scheduled run and most recent scheduled success for the browser matrix, deep regression, CodeQL, Gitleaks, and platform audit. It reports `healthy`, `failing`, `stale`, or `missing-success`; it never treats manual dispatch as schedule evidence.
- The monthly audit summary includes each scheduled workflow's status, latest successful timestamp, and freshness limit. Non-healthy schedules appear in report limitations for follow-up.
