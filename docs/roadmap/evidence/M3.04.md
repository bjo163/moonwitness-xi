## Coverage and findings

- The seeded `base.partner_address` menu metadata marks the model as `developmentOnly`.
- Normal mode hides that entry from model navigation and the command palette.
- Development Mode reveals it in both places and retains the setting after a page reload.
- A normal `user` account is created using the API. Its `/api/models` listing and direct model read remain governed by server ACLs; changing the Board's Development Mode does not change authorization.
- Investigation found that the toggle synchronously dispatched a cross-component event from inside a React state updater. This caused a React render warning. The update now changes local state in the updater and persists/broadcasts from an effect after render.
- The full visual suite found the dashboard's seeded audit-event cards expanding to intrinsic content width (1,599 px) on a 375 px viewport. The audit feed and its grid cards now constrain intrinsic width and wrap change summaries; visual checks pass in both themes.
