## Implemented

- Playwright now retains a trace on failure and continues to capture failure screenshots. Trace archives stay local to the runner and are deliberately excluded from GitHub artifacts because Playwright traces may contain request credentials; CI uploads only JUnit/retry diagnostics and visual screenshots after scanning text reports for credential patterns.
- Added a manually dispatched `Visual review` workflow. It runs the existing audited responsive screens against isolated PostgreSQL and publishes screenshot candidates for human review. It does not write or accept source-controlled baselines.
- Existing visual audit screenshots cover login at mobile, tablet, desktop and protected screens across viewport sizes and light/dark themes. The M3.02 evidence records human review of representative screens.
