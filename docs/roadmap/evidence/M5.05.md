## Delivered

- Added a deterministic generator that produces 24 individual typed React components from the package's canonical SVGs.
- Exposed individual `@moonwitness/ui/icons/<name>` exports and a convenience barrel. Direct imports resolve to individual modules so an app importing one icon does not load the full inventory.
- Components use `currentColor`, configurable size, React `useId` for collision-free title IDs, and decorative `aria-hidden` by default. A supplied `title` enables the accessible image name.
- Replaced the Profile and Settings menu glyphs in Board with package exports as a real consumer smoke test.
