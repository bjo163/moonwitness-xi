## Contract and result

The manual Pages workflow may publish from a full lowercase commit SHA when dispatched from `main`. It verifies the value is a commit object, confirms it is an ancestor of trusted `main`, checks the exact source SHA has a successful main push `ci-gate`, checks out that commit detached, and rebuilds the documentation from that immutable source. The retry path remains within the Pages workflow; it does not create a tag, bump application version, publish images, or create a GitHub Release. A tagged publication source must be a published stable release; prerelease tags fail closed.
