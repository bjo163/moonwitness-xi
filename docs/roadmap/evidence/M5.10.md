## Delivered

- Added direct, typed subpaths in `@moonwitness/ui` for `Field`, `Skeleton`, `EmptyState`, `PageHeader`, `Panel`, `Toolbar`, `Pagination`, and semantic `Table` parts. Each import compiles as its own module and does not require a package barrel.
- `Field` takes an explicit DOM `htmlFor`, typed form-control element, label, optional description/error, and required state. It connects IDs, `aria-describedby`, `aria-invalid`, and `aria-required` to the control.
- `Skeleton` is decorative to assistive technology by default and observes reduced motion. Empty and page/panel/toolbar components accept consumer-owned React content; none encode model or route behavior.
- `Pagination` is controlled, clamps display values, has bounded disabled previous/next buttons, and lets the consumer own page fetching and state.
- Table exports semantic caption/head/body/row/header/cell wrappers and a scoped responsive overflow container.
- Added scoped design-token CSS and documented public subpaths/contracts. Migrated the Board Skeleton path to a thin package re-export, preserving Board import paths and dimensions through utility class overrides.
