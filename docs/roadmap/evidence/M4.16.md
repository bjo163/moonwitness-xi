## Contract recorded

- [Compatibility policy](../../engineering/compatibility.md) defines supported SDK root exports, current unversioned API behavior, addon manifest/upgrade contract, SemVer and deprecation windows, and breaking-change documentation.
- Upgrade instructions cover application backups and restore rehearsal, addon versions and transactional forward hooks, preservation of seed identities and user edits, lack of automatic downgrade, paired API/client upgrades, session invalidation, and post-upgrade integrity checks.
- The policy distinguishes current supported behavior from future release-gate enforcement assigned to M7.06; it does not claim that future automation is already active.
