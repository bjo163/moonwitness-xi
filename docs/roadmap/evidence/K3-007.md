## Implemented

- Added `findDuplicateCandidates` to `@moonwitness/research` public exports.
- It compares validated assertions using normalized claim features, polarity, scope, context attribution, lifecycle/review eligibility, epistemic/review state, and readable evidence selectors. Candidate rows are explicitly unresolved and contain rationale; no assertion is changed, merged, or assigned a canonical identity.
- Visibility values are strict; only records allowed by the supplied access callback participate. Private records and evidence attached to unreadable assertions are omitted. Readable malformed records fail with a generic error.
- Work and output are bounded by visible assertion/evidence limits, per-claim byte/codepoint limits, feature-term limits, and a configurable pair limit. Callers must bound source retrieval before materializing the input.
- Evidence selector matching uses recursively canonicalized validated selectors, including nested range fields. The scorer reports feature overlap only; it does not claim semantic equivalence or certainty.
- Tests use synthetic fixtures only. No API route, canonical graph integration, persisted score, automated merge, or real G3 research fact was added.
