## Protocol enforced

- Inspect branch and worktree before editing; preserve unrelated/untracked user files.
- Run task-specific tests, lint/format/typecheck as applicable, inspect the diff for secrets, explicit `any`, generated drift and accidental files.
- Stage only known task-owned paths and run `git diff --cached --check`.
- Use a Conventional Commit with the roadmap task ID; add `Refs #<number>` only when an issue exists and never use `Closes` by default.
- Push to `dev` without force, then compare local `HEAD` with `git ls-remote origin refs/heads/dev`.
- Record CI as pending, failed, gated or verified for that exact SHA. A push alone is not a passing check or production release.
- No empty commit for no-op; no per-task application version bump. Main is updated only through the promotion PR.
