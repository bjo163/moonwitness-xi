## Report contract

- Reuses the single open `dev` → `main` PR and updates one delimited report block; human-authored body text outside the block is preserved. Malformed or duplicate delimiters fail closed.
- Binds source and base to full commit SHAs, derives task IDs from commit subjects/changed paths/ROADMAP diff, and links each task to its card at the source SHA.
- Reads check runs for the exact event commit SHA. No check records are described as pending, and detail links are accepted only for the same repository's GitHub Actions run or commit pages.
- Includes the shared release planner result when a stable release baseline tag exists; otherwise explicitly reports that a release baseline is unavailable. It does not publish or deploy an application.
- Includes the existing promotion risk classification and leaves approval-required label/auto-merge behavior in the existing guarded workflow steps.
- Does not add `Closes`/`Fixes` references or modify GitHub issue status.
