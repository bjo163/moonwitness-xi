# M1.11 — Remove application deployment workflows

The staging/production deployment workflow was removed from `.github/workflows/deploy.yml`.
The former workflow contained deploy-hook calls for staging and production. Release
publication to GHCR and GitHub Releases remains separate and is not an application deploy.

Container validation now builds API and Board from the production Docker targets, starts
them with a disposable PostgreSQL service using an isolated Compose project, checks API
root/readiness and Board root, then stops the API and verifies graceful shutdown. The
smoke script hardcodes only local test credentials and deletes its temporary database
volume on exit. It never reads deployment hook URLs or accesses an external service.
