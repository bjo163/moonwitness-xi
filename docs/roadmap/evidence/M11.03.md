## Contract and result

- Stable identity is GitHub numeric repository ID plus roadmap Task ID; title is not identity.
- Remote discovery reads every open and closed Issues REST page (`per_page=100`) and ignores pull request entries.
- Planner operations are `create`, `update`, `noop` and `conflict`; duplicate identities and malformed managed-block delimiters fail closed.
- Generated text is bounded by managed-block markers; notes outside it are preserved. No operation deletes an issue, comments, or human labels.
- Dry-run is the default. `--apply` is required for serial writes. Apply re-reads and hashes current remote state, refuses stale plans, and checks all conflicts before the first write.
- If a create response fails ambiguously, the executor re-reads the stable marker before surfacing the error, preventing blind duplicate retries.
- The CLI validates the 148-task roadmap before GitHub API access. Public plan reads omit authorization when `GITHUB_TOKEN` is absent; apply and all mutating endpoints require the scoped token from that environment variable.
