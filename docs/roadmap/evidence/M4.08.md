## Contract and result

- Password-kind model fields are marked `writeOnly`, removed by model JSON serialization, excluded from field metadata where appropriate, and blocked from explicit REST/JSON-RPC field selection, filter, and sort probes.
- REST details and JSON-RPC generic reads return serialized model records; nested profile relations do not expose password hashes.
- Audit snapshots exclude model-declared hidden fields and names matching password/token/secret/credential/hash. Outbox record payload uses the same safe snapshot.
- Board table columns and CSV exports omit fields marked `writeOnly`; CSV keeps its formula-injection escaping.
- Central logger redacts authorization/cookie headers, password, refresh token, and access token fields, including matching nested structured fields.
- Database errors return safe generic messages and log only safe database context instead of SQL bindings.
