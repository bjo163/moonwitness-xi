## Contract

- Stable documentation URLs are `/vX.Y.Z/`; `/latest/` resolves only to the newest published stable release that has a verified docs archive.
- The root is a version selector; trusted main docs live at `/next/`; dev remains preview-only.
- GitHub Releases retain immutable deterministic `docs-site-vX.Y.Z.tar.gz` archives. Pages expands the five newest stable releases; older archives remain downloadable from their immutable Releases.
- Archive package canonicalizes run-specific metadata, and extraction rejects malformed checksums, unsafe paths, duplicate entries, symlinks and unsupported tar types.
- Asset reconciliation is read-before-write and requires exact digest and size. Existing mismatched assets fail closed; no clobber/overwrite is allowed.
- A source/version/channel badge is visible in the docs portal, and the manifest records exact source SHA/ref, stable paths and retention policy.
