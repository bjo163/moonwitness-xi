## Contract and result

Manual Pages publication from a release tag accepts only `vMAJOR.MINOR.PATCH` without prerelease or build metadata. It also requires an existing, published GitHub Release whose `isDraft` and `isPrerelease` values are both false, then checks that the tag commit is reachable from `main`. This prevents an RC or un-published tag from replacing the stable docs root.

This does not yet preserve old docs under `/vX.Y.Z/`, create a version selector, define an explicit retention window, or map `/latest/` to the newest published stable version. The Pages artifact currently deploys one site snapshot, so M6.08 must remain partial until the historical-version retention design is implemented and tested.
