# Evidence K5-001 — local-only memory/archive intake manifest

## Status

- Status: in progress; a consent-bound local intake manifest is implemented and verified with synthetic input. Archive content is not parsed or copied; real-data import remains inactive.
- Date: 2026-10-15 (Asia/Jakarta).
- Tested base: `567837b9a7a6a684e04d549da444a26ed7a9bccc` on `dev`; K5-001 changes are currently local and uncommitted.
- Dependencies: K1-004 provenance contract and K0-005 privacy/consent policy are accepted.
- Risk: privacy-sensitive. No real account, witness, or child data was read or added.

## Result

- Added a typed `moonwitness-private-archive-import/v1` manifest schema with source kind, local path, export timestamp, SHA-256, byte length, recorded time, and source-scoped consent fields.
- Added a local manifest writer that accepts only an explicit `granted` consent state, binds consent to the exact source kind/path/checksum, hashes only a local regular file, writes metadata only, and refuses network/absolute/parent paths, symbolic links, mismatched consent, empty files, and overwrites.
- Added structural and source-binding validation. It does not verify that a declared consent decision is authentic or legally sufficient.
- Added synthetic tests for the valid manifest, missing/denied/withdrawn consent, path and checksum mismatch, remote/absolute/parent paths, overwrite rejection, unknown fields, and source scope mismatch.
- No raw archive bytes, consent documents, account exports, or private records were copied into the repository. The manifest creator does not parse, copy, upload, or publish archive contents.
