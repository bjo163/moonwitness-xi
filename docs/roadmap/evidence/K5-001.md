## Result

- Added a typed `moonwitness-private-archive-import/v1` manifest schema with source kind, local path, export timestamp, SHA-256, byte length, recorded time, and source-scoped consent fields.
- Added local manifest and import functions that accept only explicit `granted` consent, bind it to exact source kind/path/checksum, and refuse network/absolute/parent paths, symbolic links, mismatched consent, empty files, and overwrites.
- Requires the canonical intake root to resolve outside the caller-supplied workspace root, so a mistaken in-repository path fails before reading the source or writing a manifest.
- `importPrivateArchive` copies a local file into external storage using exclusive creation and mode `0600`, verifies the copied SHA-256 and byte length, and removes only the file it created if copying, verification, or manifest creation fails. It does not parse, upload, or publish the archive.
- Added structural and source-binding validation. It does not verify that a declared consent decision is authentic or legally sufficient.
- Added synthetic tests for successful local copy, denied/mismatched consent, checksum verification, external-root checks, symlink rejection, manifest rollback, source/destination overlap, path validation, overwrite rejection, and schema/source binding.
- No raw archive bytes, consent documents, account exports, or private records were added to the repository. Test-only synthetic bytes are copied into temporary directories outside the workspace.
