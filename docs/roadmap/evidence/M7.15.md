## Trigger contract

| Workflow                   | Required invariant                                                                                                                                                                                |
| -------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `release.yml`              | Publishing needs explicit `workflow_dispatch`, `publish=true`, a version tag, successful verify job, and exact remote tag SHA check before writes.                                                |
| `release-prepare.yml`      | Dispatch is accepted only on `dev`; requested SHA equals event SHA and publication uses expected remote SHA.                                                                                      |
| `dependency-candidate.yml` | Candidate starts from `dev`, publication verifies source/candidate identity and expected-ref, then explicitly dispatches promotion and full CI because bot pushes do not trigger those workflows. |
| `pages.yml`                | Manual preview/publication refs are restricted to protected `dev`/`main`, and release tag source is validated before checkout.                                                                    |
| `visual-review.yml`        | Dispatch is limited to `dev`; checkout uses immutable event SHA without persisted credentials or arbitrary ref input.                                                                             |
