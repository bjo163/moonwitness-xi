- `node scripts/smoke-containers.mjs` built the current API and Board images, started them with an ephemeral PostgreSQL 16 service, and completed the non-AI smoke flow. The smoke script inspected the actual `${projectName}_default` Docker network and required `Internal=true` before starting the API. API, database, and Board requests were issued from inside the isolated API container; the approved local corpus checks and graceful API shutdown passed. Compose then removed only this smoke project's containers, network, and volumes.
- The network property check is a Docker runtime policy check. It does not probe a live external endpoint; image builds and base image/package retrieval happen before runtime containers join the internal network.
- Exact commands and results are recorded in [the operations baseline](../../operations/local-ai-evaluation.md). Repeatable model and offline evaluation steps are in [the K7-006 protocol](../../../research/evaluations/K7-006-protocol.md).
