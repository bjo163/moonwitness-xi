## Limits and operations

- Local filesystem storage still requires persistent shared storage between API instances serving the same database. Cloud/object storage, malware scanning, content sniffing and automated expiry policy remain unsupported.
- Reconciliation snapshots current DB references, reports checksum/size mismatches, and is dry-run by default. Deletion is an explicit operator action and only considers stale UUID-named files in bounded batches. Review output and take a backup before `--apply`.
- Archived attachment bytes do not expire automatically. Retention duration is a product/operator policy and must be decided before automatic archive expiry is enabled.
- No application deployment was performed.
