## Changes and validation

- Replaced mutable major tags for checkout, setup-node, pnpm setup, artifact upload, Pages actions, Docker actions, and paths-filter with immutable commits.
- Updated CodeQL init/analyze/SARIF upload from v3 to v4.38.2 to address the announced v3 deprecation window.
- Added `scripts/check-action-pins.mjs` and `pnpm automation:check:action-pins`; it scans every workflow and composite YAML file for external actions, rejects non-SHA refs and missing version comments, and allows only local `./...` actions without a remote pin.
- Added CI unit fixtures for mutable tags, short pins, missing version comments, malformed refs, expressions, and valid local actions.
- `pnpm test:action-pins` — passed (3 tests).
- `pnpm automation:check:action-pins` — passed; 12 workflow/composite YAML files scanned.
- `actionlint` for every workflow, `pnpm lint`, `pnpm format:check`, `pnpm docs:check`, and hosted technical CI are recorded after this implementation commit completes.

## Limits

- This validator proves reference shape and human version annotation; the upstream SHA provenance still requires review at each maintenance update. M8.05 covers scheduled update planning.
- Fork pull requests keep read-only workflow permissions from M8.01; no `pull_request_target` execution path was introduced.
