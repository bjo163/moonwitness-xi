# Evidence M7.04 — Deterministic read-only release planner

## Status

Completed on `dev` with local tests and hosted technical CI. The separate sensitive promotion gate still requires a fresh CODEOWNER approval.

## Contract

- `pnpm release:plan [--head <ref>] [--baseline-tag <tag> | --baseline-sha <sha>] [--json]` resolves immutable source and baseline commits and emits a stable JSON schema.
- Default baseline is the highest valid semantic version tag available locally; an explicit existing tag/SHA can be used to reproduce a plan.
- Feature/fix/breaking classification reuses the tested Conventional Commit classifier. Merge commits are skipped; docs/chore/CI/test commits are reported as ignored; invalid subjects fail closed.
- Plan JSON includes the classified commit metadata needed by changelog rendering without copying commit bodies into the plan artifact.
- Candidate version is always a prerelease (`-rc.1`) until a separately authorized stable transition. No releasable changes produce `no-release` and a null next version.
- Planner performs no filesystem, git-ref, GitHub, registry, or Pages writes (`writesPerformed: false`).
