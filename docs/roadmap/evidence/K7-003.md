## Implemented

- Added `retrieveLocalPassageChunk` to `@moonwitness/local-ai`. It fails closed unless the request and resolver result bind to the approved source ID, edition ID, `Q7:46` locator, exact source SHA-256, exact local rights-manifest path and hash, attribution, and public-approved visibility.
- The function verifies the artifact bytes and manifest bytes locally, parses the single exact `7|46|...` line, and checks that resolver passage text equals the source text. It performs no network or model calls and writes no canonical data.
- Retrieval requires a resolver authorization hook. The returned chunk preserves canonical citation identity, manifest attribution, visibility, and byte/scalar spans relative to the canonical passage text. Invalid UTF-8 boundaries and non-public labels fail with a generic unavailable error.
- Validated primitive values are snapshotted before awaiting the authorization hook; the hook receives an independent copy. A mutation test confirms resolver object changes during authorization cannot change returned text, citation, or visibility.
- The helper remains a package projection contract rather than an authorization boundary; the API composition below binds it to canonical records and server-side access decisions.
- Added `POST /api/research/retrieval/chunk` in `@moonwitness/api`. It accepts only canonical evidence ID and optional byte offsets; user, company, visibility, source selector, review state, and rights values are derived from authenticated request context, canonical evidence resolution, and the local Q7:46 snapshot.
- The route requires an authenticated user or superadmin with an active company context; `resolveConceptProfileEvidence` enforces active user and membership access. It returns only chunk, citation, and span with `Cache-Control: private, no-store`; inaccessible, restricted, mismatched, or unresolved evidence receives a generic unavailable response.
- The API route is hard-limited to the exact owner-approved Q7:46 source/edition/locator/digest and calls `readQuranPassageSnapshot` with `use: 'read_analyze'` to pass the exact local artifact and rights-manifest bytes to the package verifier. It performs no external fetch, model call, or canonical write.
