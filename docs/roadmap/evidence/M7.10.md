## Contract and result

The release verify workflow builds API and Board production images once, generates SPDX JSON SBOMs, writes checksums for the transport bundle and public SBOM assets, and uploads the exact bundle. A separate `attest-artifact` job attests the tar, manifest, SBOMs, and asset checksum list. The publish job pushes those verified images, creates digest-bound provenance and SBOM attestations, ensures a draft Release exists, reconciles SBOM/checksum assets by exact SHA-256 digest and size, and only publishes after asset verification. Existing conflicting assets fail closed; ambiguous uploads are re-read before retry; no `--clobber` is used.
